## Propósito

Explorar el mundo de la concurrencia utilizando hilos. En esta unidad aprenderás cómo un solo programa puede ejecutar múltiples secuencias de instrucciones aparentemente al mismo tiempo, reconocerás beneficios como mantener una aplicación responsiva y acelerar cálculos mediante paralelismo, y enfrentarás el desafío de gestionar de forma segura los datos compartidos entre hilos.
