## Propósito

Hacer una introducción práctica a la programación gráfica moderna con OpenGL. En esta unidad usarás como caso de estudio el ejemplo del triángulo simple para entrar al pipeline programable, entender cómo fluye la información desde el CPU hasta la GPU y observar cómo shaders, buffers y estado gráfico colaboran para producir una imagen.
